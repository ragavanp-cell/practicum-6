# TrainSphere — Corporate Training, Workshops & Reduction Services

Implements the **CSS Positioning Elements** practicum showcase (`position: relative`, `position: absolute` with `Top Left`, `Top Right`, `Centered`, `Bottom Left`, `Bottom Right` overlays + interactive `Try it Yourself` buttons, `position: fixed`, `position: sticky`, and `z-index`) and fulfills all 15 requirements of the **WebTech Practicum Checklist (25CS208)**.

## Unique Project File Names
- `index.html` — Root entry point for GitHub Pages and Vercel
- `trainsphere-positioning-styles.css` — Positioning overlays, Flexbox navbar, Quadrant layout, 3-column Grid, Media Queries, and Light/Dark themes
- `trainsphere-positioning-logic.js` — Interactive positioning inspector, Form validation, Timers, Fetch API benchmarks, CRUD Task Manager, and Quiz array
- `vercel.json` — Vercel static deployment configuration

## Deploy to GitHub & Vercel
1. Extract this ZIP archive into a local folder.
2. Create a new GitHub repository (e.g., `trainsphere-positioning-practicum`) and upload all files to the root directory.
3. Log in to [Vercel](https://vercel.com), click **Add New → Project**, import your GitHub repository, and click **Deploy**.
